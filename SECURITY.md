# Política de segurança

## Versões suportadas

Enquanto o projeto estiver em pré-release, somente a versão mais recente da linha `0.x` receberá correções de segurança.

## Reportando uma vulnerabilidade

Não abra uma issue pública com detalhes exploráveis. Use o recurso **Private vulnerability reporting** do repositório no GitHub.

Inclua, quando possível:

- versão afetada;
- impacto observado;
- passos mínimos para reprodução;
- proposta de mitigação.

O recebimento será confirmado assim que possível. A correção e a divulgação serão coordenadas antes da publicação dos detalhes.
